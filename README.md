# Nelikvid Dashboard

Одностраничное веб-приложение (frontend-only) для анализа неликвидов на основе выгрузок из 1С.

## 🎯 Функциональность

- **Парсинг Excel файлов** из 1С прямо в браузере (без сервера)
- **Загрузка трёх файлов**:
  - Ведомость остатков по складам
  - Отчёт продаж по периодам
  - Список неликвидов от РОПа
- **Сопоставление и анализ** по Коду + Ширине
- **Интерактивный дашборд** с графиками и KPI
- **Фильтрация и поиск** по наименованию, складу, бренду, статусу
- **Экспорт отчёта** в Excel с сохранением форматирования

## 📊 Визуализация

- KPI-карточки (позиции, остатки, продажи, выручка)
- График остатков и продаж по складам
- Диаграмма распределения по статусам
- Топ-10 брендов по остатку
- Детальная таблица со статусами неликвидов

## 🚀 Как использовать

1. Откройте `index.html` в браузере
2. Выберите три файла Excel:
   - **Остатки** — Ведомость по товарам на складах из 1С
   - **Продажи** — Отчёт «Продажи для аналитики»
   - **Неликвиды** — Excel лист «Неликвид» со списком РОПа
3. Нажмите кнопку **«Обработать»**
4. Используйте фильтры для анализа данных
5. Нажмите **«Скачать отчёт»** для экспорта в Excel

## 🔧 Технологии

- **JavaScript** (vanilla, без фреймворков)
- **SheetJS (XLSX)** — парсинг Excel через CDN
- **Chart.js** — красивые графики
- **Intl.NumberFormat** — форматирование чисел по-русски

## 🔄 Логика сопоставления

1. **Парсинг имён**: из текста извлекаются Код (3 цифры + буквы) и Ширина (число + 'м')
2. **Ключ мэчинга**: Код + Ширина
3. **Для каждого неликвида РОПа**:
   - Ищатся остатки по Коду и Ширине
   - По каждому складу агрегируются продажи
   - Определяется статус:
     - "Остаток есть, продаж нет"
     - "Остаток и продажи есть"
     - "Продан / остатка нет"
     - "Нет данных"

## 📝 Статусы позиций

| Статус | Описание |
|--------|---------|
| Остаток есть, продаж нет | Неликвид с остатком, без движения |
| Остаток и продажи есть | Есть и остаток, и продажи |
| Продан / остатка нет | Продан полностью, остатка нет |
| Нет данных | Не найдены остатки или продажи |

## 🎨 Форматирование данных

- Числа форматируются с пробелом-разделителем (1 000 000)
- Ширина показывается в метрах (2.7м, 3.2м)
- Выручка форматируется как RUB

## ⚙️ Требования

- Интернет для загрузки CDN библиотек (XLSX, Chart.js)
